# Drawing — прототип редактора

Небольшой растровый редактор на C++17 / Qt Widgets для проверки гипотезы этапа 0. Рабочий комплект: Qt 5.15.2 + MinGW 8.1.0, 64 бит.

## Запуск

После сборки открыть `dist/Drawing/Drawing.exe`. Эта папка содержит необходимые библиотеки; переносить нужно всю папку, а не только EXE.

```powershell
./build.ps1
```

Скрипт использует `F:\Qt\5.15.2\mingw81_64` и `F:\Qt\Tools\mingw810_64`. Пути можно изменить параметрами `-QtRoot` и `-CompilerRoot`. Исходный проект открывается в Qt Creator через `Drawing.pro`.

## Управление

| Действие | Управление |
|---|---|
| Карандаш | B или кнопка слева |
| Ластик цветом Back | E |
| Перемещение холста | H; средняя кнопка мыши; Пробел + перетаскивание |
| Масштаб под курсором | Колесо мыши |
| Вписать холст / 100% | Ctrl+0 / Ctrl+1 |
| Ширина штриха | Поле на верхней панели, в пикселях изображения |
| Выбрать цвета | Front и Back; системный диалог Windows |
| Поменять цвета местами | X |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |
| Новый холст | Ctrl+N |
| Открыть PNG или DRW | Ctrl+O |
| Сохранить проект / сохранить как | Ctrl+S / Ctrl+Shift+S |
| Экспортировать PNG | Ctrl+Shift+E |
| Включить управление точкой схода | P; затем тянуть круглый маркер |
| Панель перспективы | Меню «Вид» |

Штатные кнопки окна позволяют свернуть, развернуть и восстановить окно. Изменение размера окна не меняет пиксели холста. В узком окне дополнительные команды панели доступны через её кнопку переполнения `»`.

Карандаш и ластик рисуют только по изображению. Служебная сетка и точка схода не входят в экспорт PNG. Параметры перспективы сохраняются в проекте и участвуют в отмене. Это минимальная одноточечная проверка, а не реализация последующих режимов перспективы.

## Файлы

`.drw` — обычный ZIP-контейнер с двумя элементами:

- `drawing.png` — изображение, включая прозрачность при импорте.
- `project.json` — идентификатор `Drawing`, версия схемы 1, размеры и параметры перспективы.

PNG открывается как импортированный несохранённый проект. «Сохранить» записывает `.drw`; экспорт PNG не сбрасывает несохранённые изменения проекта. Ластик закрашивает цветом Back, а не стирает до прозрачности.

Перед заменой или закрытием изменённого документа появляется запрос «Сохранить / Не сохранять / Отмена». Отмена пути или ошибка записи не закрывает документ. Файл проекта заменяется атомарно через `QSaveFile` после формирования контейнера.

Для ZIP используются внутренние классы Qt `QZipReader`/`QZipWriter`, изолированные в `src/project.cpp`. Поэтому сборка и поставляемые DLL привязаны к конкретному комплекту Qt 5.15.2; при обновлении Qt этот компонент нужно проверить или заменить публичной ZIP-библиотекой. Qt и системные файлы не изменяются.

Ограничения прототипа: до 8192 пикселей по стороне и до 16 млн пикселей суммарно, один растровый слой. История отмены ограничена размером документа (ориентир 128 МБ для снимков истории); пиковая память с текущим изображением и сериализацией может быть выше.

## Автоматические проверки

```powershell
./test.ps1 -Platform windows
./test.ps1 -Platform offscreen
```

`windows` проверяет также реальные диалоги Qt; тестовые окна могут кратковременно появляться. `offscreen` проверяет холст и файлы, но пропускает системные диалоги: Qt 5.15.2 на Windows несовместим с таким сочетанием. Для автотестов отключено появление системных окон аварийного завершения; обычный запуск редактора не меняет эту настройку.

Результаты и снимки окна — в `build/windows-results` и `build/offscreen-results`. Набросок для ручной проверки — `build/windows-results/Набросок.drw`. Папки `build`, `dist` и старые результаты GIMP `.stage0` не входят в Git.

Проверяются штрихи, цвет ластика, отмена/повтор, навигация без изменения пикселей, перемещение точки схода, PNG и DRW, прозрачность, некорректные файлы, отмена закрытия, сохранение перед закрытием, сохранность документа после неудачной загрузки и компоновка окна в двух размерах.

## Пользовательская проверка

- ☐ Оценить удобство карандаша, ластика, масштаба и перемещения холста.
- ☐ Проверить системный выбор Front/Back, новый размер холста и файловые диалоги.
- ☐ Проверить разворачивание, сворачивание и восстановление окна на своём мониторе.
- ☐ Поиграться с точкой схода через P и вернуться к карандашу через B.
- ☐ Подтвердить пригодность основы для следующего шага. До этого этап 0 не закрыт.

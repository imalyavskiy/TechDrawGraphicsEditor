# TechDraw — «Технический рисунок» / Technical Drawing

Небольшой растровый редактор на C++17 / Qt Widgets для проверки гипотезы этапа 0. Рабочий комплект: Qt 5.15.2 + MinGW 8.1.0, 64 бит.

## Запуск

После сборки открыть `dist/TechDraw/TechDraw.exe`. Эта папка содержит необходимые библиотеки; переносить нужно всю папку, а не только EXE.

```powershell
./build.ps1
```

Скрипт использует `F:\Qt\5.15.2\mingw81_64` и `F:\Qt\Tools\mingw810_64`. Пути можно изменить параметрами `-QtRoot` и `-CompilerRoot`. Исходный проект открывается в Qt Creator через `TechDraw.pro`.

Исходник значка хранится в `resources/techdraw.svg`. Команда `py tools/generate_icon.py` создаёт из него растровый ресурс Qt и многоразмерный значок Windows. Краткое имя приложения, исполняемого файла и каталога поставки — `TechDraw`; полное имя продукта в свойствах Windows — `Technical Drawing`.

## Управление

| Действие | Управление |
|---|---|
| Карандаш | B или кнопка слева |
| Кисть | K или кнопка слева |
| Ластик цветом Back | E |
| Отрезок от последней точки | Shift + щелчок; повторные щелчки продолжают ломаную |
| Отрезок с ограничением угла | Ctrl+Shift + щелчок; шаг 15° |
| Перемещение холста | H; средняя кнопка мыши; Пробел + перетаскивание |
| Масштаб под курсором | Колесо мыши |
| Вписать холст / 100% | Ctrl+0 / Ctrl+1 |
| Ширина штриха | Поле на верхней панели; карандаш, кисть и ластик запоминают собственное значение |
| Выбрать цвета | Front и Back; системный диалог Windows |
| Поменять цвета местами | X |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |
| Новый холст | Ctrl+N; диалог запоминает последний успешно созданный размер |
| Открыть PNG или DRW | Ctrl+O |
| Открыть недавний файл | Файл → Недавние файлы; сохраняются пять последних |
| Сохранить проект / сохранить как | Ctrl+S / Ctrl+Shift+S |
| Экспортировать PNG | Ctrl+Shift+E |
| Включить управление точкой схода | P; затем тянуть круглый маркер |
| Переместить горизонт | P; затем тянуть линию горизонта в пределах холста |
| Настроить опорные линии | Панель перспективы: шаг, отступ и нарастание непрозрачности |
| Панель перспективы | Меню «Вид» |

Штатные кнопки окна позволяют свернуть, развернуть и восстановить окно. Изменение размера окна не меняет пиксели холста. Кнопки панелей показываются пиктограммами, а название команды и горячая клавиша — во всплывающей подсказке. В узком окне дополнительные команды панели доступны через её кнопку переполнения `»`.

Программа отдельно запоминает последний каталог открытия и последний каталог сохранения. Успешное открытие или сохранение добавляет файл в постоянный список «Недавние файлы» и поднимает повторно использованный файл наверх. Экспорт PNG обновляет каталог сохранения, но не добавляет PNG в список недавних документов.

Карандаш, простая кисть и ластик рисуют только по изображению. Обычное протягивание создаёт свободный штрих. После первого щелчка `Shift` показывает будущий отрезок и позволяет последовательно строить ломаную; `Ctrl+Shift` ограничивает направление ближайшим углом, кратным 15°. Каждое звено отдельно участвует в отмене. Опорные линии перспективы сходятся в общей точке. Если точка находится за холстом, полезная часть луча видна между точкой и холстом; после прохождения дальней границы холста луч заканчивается. Лучи, не пересекающие холст, скрываются, а горизонт проходит через всю область просмотра.

Точка схода свободно перемещается, прилипает к горизонту в пределах 10 экранных пикселей и снимается с него при дальнейшем движении. У прикреплённой точки внутри белого маркера появляется цветной концентрический круг; у свободной точки центр белый. Перемещаемый горизонт переносит прикреплённую точку, но не влияет на свободную.

В панели перспективы вместо количества лучей задаётся угловой шаг от 1° до 30°. Отступ от точки, начальная и итоговая непрозрачность и длина нарастания измеряются в экранных пикселях и процентах, поэтому сохраняют внешний вид при масштабировании. Эти поля собраны в блоке «Настройки точек схода». Ниже расположен список «Точки схода»; пока в нём одна точка со своим цветом лучей. «Сохранить» запоминает пять значений для новых документов, импортированных PNG и открываемых проектов. Кнопка доступна, только когда хотя бы одно значение отличается от действующего пресета; после сохранения или сброса она отключается. «Сбросить» удаляет сохранённый пресет и возвращает `10°`, `12 px`, `10%`, `70%`, `50 px`. Параметры отображения не изменяют проект и не входят в его Undo.

Сверху вниз расположены блоки «Линия горизонта», «Настройки точек схода» и «Точки схода». Линия горизонта имеет собственные цвет, непрозрачность и ширину `0,1–20 px`, независимые от оформления лучей точки схода. Файл `.drw` хранит координаты точки схода и положение горизонта. Эти геометрические параметры участвуют в Undo проекта. Видимость и параметры отображения в файл не записываются. Служебная сетка, горизонт и точка схода не входят в экспорт PNG.

## Файлы

`.drw` — обычный ZIP-контейнер:

- `drawing.png` — изображение, включая прозрачность при импорте.
- `project.json` — идентификатор `Drawing`, версия схемы 3, размеры, координаты точки схода и горизонта, подписи операций и текущая позиция истории. Идентификатор и имя внутреннего файла `drawing.png` сохранены для совместимости с уже созданными проектами.
- `history/state-XXXX.png` — состояния рисунка для отмены и повтора. Если соседние операции меняют только координаты точки схода или горизонта, они ссылаются на одно изображение без дублирования.

После повторного открытия `.drw` команды отмены и повтора продолжают работать, включая случай, когда проект был сохранён в середине истории. Формат версии 3 сохраняет до 30 операций и записывает для перспективы только координаты точки схода и горизонта. Проекты версий 1 и 2 открываются, но находившиеся в них параметры отображения игнорируются. PNG открывается как импортированный несохранённый проект. «Сохранить» записывает `.drw`; экспорт PNG не сбрасывает несохранённые изменения проекта. Ластик закрашивает цветом Back, а не стирает до прозрачности.

Перед заменой или закрытием изменённого документа появляется запрос «Сохранить / Не сохранять / Отмена». Отмена пути или ошибка записи не закрывает документ. Файл проекта заменяется атомарно через `QSaveFile` после формирования контейнера.

Для ZIP используются внутренние классы Qt `QZipReader`/`QZipWriter`, изолированные в `src/project.cpp`. Поэтому сборка и поставляемые DLL привязаны к конкретному комплекту Qt 5.15.2; при обновлении Qt этот компонент нужно проверить или заменить публичной ZIP-библиотекой. Qt и системные файлы не изменяются.

Ограничения прототипа: до 8192 пикселей по стороне и до 16 млн пикселей суммарно, один растровый слой, до 512 МБ на файл `.drw`. История отмены ограничена размером документа (ориентир 128 МБ для снимков истории и не более 30 операций); пиковая память и размер проекта с текущим изображением и сериализацией могут быть выше, чем без истории.

## Автоматические проверки

```powershell
./test.ps1 -Platform windows
./test.ps1 -Platform offscreen
```

`windows` проверяет также реальные диалоги Qt; тестовые окна могут кратковременно появляться. `offscreen` проверяет холст и файлы, но пропускает системные диалоги: Qt 5.15.2 на Windows несовместим с таким сочетанием. Для автотестов отключено появление системных окон аварийного завершения; обычный запуск редактора не меняет эту настройку.

Результаты и снимки окна — в `build/windows-results` и `build/offscreen-results`. Набросок для ручной проверки — `build/windows-results/Набросок.drw`. Папки `build`, `dist` и старые результаты GIMP `.stage0` не входят в Git.

Проверяются карандаш, кисть, ластик, отдельные и постоянные значения их ширины, связанные отрезки, ограничение угла, сохранение обеих ветвей Undo/Redo и их подписей, совместимость с прежними версиями DRW, отделение оформления перспективы от файла проекта, раздельные каталоги открытия и сохранения, порядок и ограничение списка недавних файлов, запоминание размера нового холста без изменения при отмене диалога, панель без текстовых подписей на кнопках, навигация без изменения пикселей, перемещение точки схода, PNG и DRW, прозрачность, некорректные файлы, отмена закрытия, сохранение перед закрытием, сохранность документа после неудачной загрузки и компоновка окна в двух размерах.

## Пользовательская проверка

- ✓ Оценить удобство карандаша, кисти, ластика, цепочки `Shift`, угловой привязки `Ctrl+Shift`, масштаба и перемещения холста.
- ✓ Проверить системный выбор Front/Back, новый размер холста и файловые диалоги.
- ✓ Создать холст нестандартного размера, перезапустить программу и проверить, что диалог нового холста предлагает этот размер.
- ✓ Проверить раздельное восстановление каталогов открытия и сохранения, меню из пяти недавних файлов и отдельную ширину каждого рисующего инструмента после перезапуска.
- ✓ Проверить разворачивание, сворачивание и восстановление окна на своём мониторе.
- ✓ Сделать несколько штрихов и изменений перспективы, выполнить отмену, сохранить `.drw`, открыть его заново и проверить доступность `Ctrl+Z` и `Ctrl+Y`.
- ✓ Поиграться с точкой схода через P и вернуться к карандашу через B.
- ✓ Подтвердить пригодность основы для следующего шага. Этап 0 принят пользователем 11 сентября 2026 г.

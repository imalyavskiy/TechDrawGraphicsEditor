# Drawing — прототип редактора

Небольшой растровый редактор на C++17 / Qt Widgets для проверки гипотезы этапа 0. Рабочий комплект: Qt 5.15.2 + MinGW 8.1.0, 64 бит.

## Запуск

После сборки открыть `dist/Drawing/Drawing.exe`. Эта папка содержит необходимые библиотеки; переносить нужно всю папку, а не только EXE.

```powershell
./build.ps1
```

Скрипт использует `F:\Qt\5.15.2\mingw81_64` и `F:\Qt\Tools\mingw810_64`. Пути можно изменить параметрами `-QtRoot` и `-CompilerRoot`. Исходный проект открывается в Qt Creator через `Drawing.pro`.

## Управление

| Действие | Управление |
|---|---|
| Карандаш | B или кнопка слева |
| Кисть | K или кнопка слева |
| Ластик цветом Back | E |
| Отрезок от последней точки | Shift + щелчок; повторные щелчки продолжают ломаную |
| Отрезок с ограничением угла | Ctrl+Shift + щелчок; шаг 15° |
| Перемещение холста | H; средняя кнопка мыши; Пробел + перетаскивание |
| Масштаб под курсором | Колесо мыши |
| Вписать холст / 100% | Ctrl+0 / Ctrl+1 |
| Ширина штриха | Поле на верхней панели, в пикселях изображения |
| Выбрать цвета | Front и Back; системный диалог Windows |
| Поменять цвета местами | X |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |
| Новый холст | Ctrl+N |
| Открыть PNG или DRW | Ctrl+O |
| Сохранить проект / сохранить как | Ctrl+S / Ctrl+Shift+S |
| Экспортировать PNG | Ctrl+Shift+E |
| Включить управление точкой схода | P; затем тянуть круглый маркер |
| Панель перспективы | Меню «Вид» |

Штатные кнопки окна позволяют свернуть, развернуть и восстановить окно. Изменение размера окна не меняет пиксели холста. Кнопки панелей показываются пиктограммами, а название команды и горячая клавиша — во всплывающей подсказке. В узком окне дополнительные команды панели доступны через её кнопку переполнения `»`.

Карандаш, простая кисть и ластик рисуют только по изображению. Обычное протягивание создаёт свободный штрих. После первого щелчка `Shift` показывает будущий отрезок и позволяет последовательно строить ломаную; `Ctrl+Shift` ограничивает направление ближайшим углом, кратным 15°. Каждое звено отдельно участвует в отмене. Служебная сетка и точка схода не входят в экспорт PNG. Параметры перспективы сохраняются в проекте и участвуют в отмене. Это минимальная одноточечная проверка, а не реализация последующих режимов перспективы.

## Файлы

`.drw` — обычный ZIP-контейнер:

- `drawing.png` — изображение, включая прозрачность при импорте.
- `project.json` — идентификатор `Drawing`, версия схемы 2, размеры, параметры перспективы, подписи операций и текущая позиция истории.
- `history/state-XXXX.png` — состояния рисунка для отмены и повтора. Если соседние операции меняют только параметры перспективы, они ссылаются на одно изображение без дублирования.

После повторного открытия `.drw` команды отмены и повтора продолжают работать, включая случай, когда проект был сохранён в середине истории. Формат версии 2 сохраняет до 30 операций в пределах действующего ограничения истории; старые проекты версии 1 открываются без истории. PNG открывается как импортированный несохранённый проект. «Сохранить» записывает `.drw`; экспорт PNG не сбрасывает несохранённые изменения проекта. Ластик закрашивает цветом Back, а не стирает до прозрачности.

Перед заменой или закрытием изменённого документа появляется запрос «Сохранить / Не сохранять / Отмена». Отмена пути или ошибка записи не закрывает документ. Файл проекта заменяется атомарно через `QSaveFile` после формирования контейнера.

Для ZIP используются внутренние классы Qt `QZipReader`/`QZipWriter`, изолированные в `src/project.cpp`. Поэтому сборка и поставляемые DLL привязаны к конкретному комплекту Qt 5.15.2; при обновлении Qt этот компонент нужно проверить или заменить публичной ZIP-библиотекой. Qt и системные файлы не изменяются.

Ограничения прототипа: до 8192 пикселей по стороне и до 16 млн пикселей суммарно, один растровый слой, до 512 МБ на файл `.drw`. История отмены ограничена размером документа (ориентир 128 МБ для снимков истории и не более 30 операций); пиковая память и размер проекта с текущим изображением и сериализацией могут быть выше, чем без истории.

## Автоматические проверки

```powershell
./test.ps1 -Platform windows
./test.ps1 -Platform offscreen
```

`windows` проверяет также реальные диалоги Qt; тестовые окна могут кратковременно появляться. `offscreen` проверяет холст и файлы, но пропускает системные диалоги: Qt 5.15.2 на Windows несовместим с таким сочетанием. Для автотестов отключено появление системных окон аварийного завершения; обычный запуск редактора не меняет эту настройку.

Результаты и снимки окна — в `build/windows-results` и `build/offscreen-results`. Набросок для ручной проверки — `build/windows-results/Набросок.drw`. Папки `build`, `dist` и старые результаты GIMP `.stage0` не входят в Git.

Проверяются карандаш, кисть, ластик, связанные отрезки, ограничение угла, сохранение обеих ветвей Undo/Redo и их подписей, совместимость с DRW версии 1, панель без текстовых подписей на кнопках, навигация без изменения пикселей, перемещение точки схода, PNG и DRW, прозрачность, некорректные файлы, отмена закрытия, сохранение перед закрытием, сохранность документа после неудачной загрузки и компоновка окна в двух размерах.

## Пользовательская проверка

- ☐ Оценить удобство карандаша, кисти, ластика, цепочки `Shift`, угловой привязки `Ctrl+Shift`, масштаба и перемещения холста.
- ☐ Проверить системный выбор Front/Back, новый размер холста и файловые диалоги.
- ☐ Проверить разворачивание, сворачивание и восстановление окна на своём мониторе.
- ☐ Сделать несколько штрихов и изменений перспективы, выполнить отмену, сохранить `.drw`, открыть его заново и проверить доступность `Ctrl+Z` и `Ctrl+Y`.
- ☐ Поиграться с точкой схода через P и вернуться к карандашу через B.
- ☐ Подтвердить пригодность основы для следующего шага. До этого этап 0 не закрыт.
